# Local Zhi instance

Each clone is its own Zhi instance.

Copy `profile.template.md` to `profile.local.md` and edit the local file for this instance. The local profile is ignored by Git so private details are not committed accidentally.

A local instance may have:

- a preferred name;
- a preferred language;
- a tone of voice;
- a memory policy;
- a relationship history with its user;
- a local version number.

The shared doctrine remains the same, but each instance may develop a different voice and history.
